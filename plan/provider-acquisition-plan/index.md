# Job Search Aggregator — Provider Acquisition Plan (MVP)

## Objective

Build a robust, scalable and maintainable job acquisition layer capable of collecting vacancies from multiple sources without requiring users to provide API keys.

The initial strategy prioritizes providers with:

- Public job APIs
- Public JSON endpoints
- Low maintenance cost
- High volume of companies
- High reliability
- Low anti-bot restrictions

This document focuses exclusively on job acquisition and provider architecture.
