# EPIC 07 — Trust & Reputation System

## Objective
Create a trust and company filtering system.


## Deliverables
- Trust engine
- Company score
- Automatic filtering
- Hidden providers system


## Tasks
- Create trust calculator
- Create trust thresholds
- Create hidden companies config
- Create company evaluator
- Create provider blacklist
- Create manual override
- Create trust cache


## Acceptance Criteria
- Companies below 6.5 are hidden
- Users can manually enable companies
- Scores are consistent
- Trust filtering works correctly
