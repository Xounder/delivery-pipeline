# Testing Philosophy

---

# Priorities

Prioritize tests for:
- ranking;
- matchmaking;
- normalization;
- provider resilience;
- trust calculations.

---

# Methodology

Prefer:
- deterministic tests;
- isolated tests;
- integration tests for providers.
