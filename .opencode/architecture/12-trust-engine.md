# Trust Engine

---

# Purpose

Evaluate provider and company trustworthiness.

---

# Trust Thresholds

| Score | Result |
|---|---|
| < 4 | blocked |
| 4-6.4 | hidden |
| >= 6.5 | visible |
| >= 8 | highlighted |

---

# Default Behavior

- scores < 6.5 are hidden by default;
- users may manually enable hidden results.

---

# Signals

- reputation;
- transparency;
- hiring quality;
- complaints.
