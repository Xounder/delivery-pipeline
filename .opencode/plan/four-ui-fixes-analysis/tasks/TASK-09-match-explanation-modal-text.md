# TASK-09 — Add Explanation Paragraph to `MatchExplanationModal.tsx`

**Layer:** frontend
**Depends on:** TASK-07
**Epic origin:** EPIC-04-trust-match-explanation-text.md

## Description

Add a human-readable explanation paragraph to the `MatchExplanationModal` component, rendered above the existing breakdown data when `matchBreakdown` is available.

## Current Structure

The modal shows:
1. Score display (percentage)
2. Breakdown sections (Matched Skills, Unmatched Skills, Seniority Match, Score Breakdown)

## Deliverable

Insert an explanation paragraph between the score display and the breakdown sections, generated by `buildMatchExplanation()` from TASK-07.

## Implementation Pattern

```tsx
// Add imports at top of file:
import { useMemo } from "react";
import { buildMatchExplanation } from "@/utils/explain";

// Inside component, add before the return statement:
const explanation = useMemo(
  () => buildMatchExplanation(matchScore, matchBreakdown),
  [matchScore, matchBreakdown],
);
```

Then, in the JSX, between the score section and the breakdown sections:

```tsx
{/* Score display (existing) — unchanged */}
<div className="mb-4 rounded-lg bg-indigo-50 p-4 text-center">
  {/* ... existing score display ... */}
</div>

{/* NEW: Explanation paragraph */}
{explanation && (
  <p className="mb-4 text-sm leading-relaxed text-gray-700">
    {explanation}
  </p>
)}

{/* Breakdown sections (existing) — unchanged */}
{matchBreakdown ? (
  <div className="space-y-4 text-sm text-gray-700">
    {/* ... */}
  </div>
) : (
  /* ... existing fallback ... */
)}
```

## Example Output

> *"85% match — Excellent match! 3 of 5 skills matched (TypeScript, React, Node.js). Seniority level is an exact match."*

## Key Constraints

- Use `useMemo` to prevent unnecessary recomputation — dependencies: `[matchScore, matchBreakdown]`
- The explanation should only render when `matchBreakdown` is available (not null)
- When `matchBreakdown` is null, the existing fallback (`matchSummary` or "unavailable" message) still shows
- The explanation paragraph should be visually subtle — `text-sm leading-relaxed text-gray-700`
- Import `buildMatchExplanation` from `@/utils/explain` (not from `@/utils`)
- Add `useMemo` to the existing React import if needed
- No changes to the existing JSX structure beyond adding the explanation
- Follow `verbatimModuleSyntax` — `import type` for type-only imports
