# TASK-08 — Add Explanation Paragraph to `TrustExplanationModal.tsx`

**Layer:** frontend
**Depends on:** TASK-07
**Epic origin:** EPIC-04-trust-match-explanation-text.md

## Description

Add a human-readable explanation paragraph to the `TrustExplanationModal` component, rendered above the existing breakdown data when `trustBreakdown` is available.

## Current Structure

The modal shows:
1. Score + label display
2. Breakdown sections (Provider Score, Company Adjustment, Freshness Score, Signals)

## Deliverable

Insert an explanation paragraph between the score display and the breakdown sections, generated by `buildTrustExplanation()` from TASK-07.

## Implementation Pattern

```tsx
// Add import at top of file:
import { useMemo } from "react";
import { buildTrustExplanation } from "@/utils/explain";

// Inside component, add before the return statement:
const explanation = useMemo(
  () => buildTrustExplanation(trustScore, trustBreakdown),
  [trustScore, trustBreakdown],
);
```

Then, in the JSX, between the score section and the breakdown sections:

```tsx
{/* Score display (existing) — unchanged */}
<div className={`mb-4 rounded-lg p-4 text-center ${trustScoreBg(trustScore)}`}>
  {/* ... existing score display ... */}
</div>

{/* NEW: Explanation paragraph */}
{explanation && (
  <p className="mb-4 text-sm leading-relaxed text-gray-700">
    {explanation}
  </p>
)}

{/* Breakdown sections (existing) — unchanged */}
{trustBreakdown ? (
  <div className="space-y-3 text-sm text-gray-700">
    {/* ... */}
  </div>
) : (
  <p className="text-sm text-gray-500">
    Detailed breakdown unavailable for this job.
  </p>
)}
```

## Example Output

> *"Score 8.2/10 — Good Trust. Posted 3 days ago (freshness: 9.0/10). Provider reputation: 7.5/10. Company size bonus adds +0.5. This employer is known in our database."*

## Key Constraints

- Use `useMemo` to prevent unnecessary recomputation — dependencies: `[trustScore, trustBreakdown]`
- The explanation should only render when `trustBreakdown` is available (not null)
- When `trustBreakdown` is null, the existing fallback message still shows
- The explanation paragraph should be visually subtle — `text-sm leading-relaxed text-gray-700`
- Import `buildTrustExplanation` from `@/utils/explain` (not from `@/utils`)
- Use `import { useMemo } from "react"` — add to existing React imports if not already present
- No changes to the existing JSX structure beyond adding the explanation paragraph
- Follow `verbatimModuleSyntax` — `import type` for type-only imports
