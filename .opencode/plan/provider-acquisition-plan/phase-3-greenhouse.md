# Phase 3 — Greenhouse Integration

## Goal

Create the first provider using a public API.

---

## Why Greenhouse First

Advantages:

- Public API
- Stable structure
- Thousands of companies
- Low maintenance
- High quality companies

---

## Features

- Search jobs
- Company identification
- Pagination support
- Job details retrieval
- Normalization

---

## Success Criteria

Provider returns normalized jobs from Greenhouse-powered companies.
