# Phase 2 — Provider Classification Layer

## Goal

Create a provider strategy system.

---

## Provider Types

### API Providers

Providers exposing public APIs.

Examples:

- Greenhouse
- Ashby
- Lever

---

### JSON Providers

Providers exposing public JSON endpoints used internally by frontend applications.

Examples:

- Workday
- Gupy
- Custom ATS implementations

---

### HTML Providers

Providers requiring HTML parsing.

Examples:

- Company career portals

---

### Browser Providers

Providers requiring browser automation.

Examples:

- Dynamic React-only job boards
- Highly protected portals

---

## Expected Result

Providers become categorized and easier to maintain.
