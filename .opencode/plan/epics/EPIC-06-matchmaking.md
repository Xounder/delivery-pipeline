# EPIC 06 — Matchmaking Engine

## Objective
Create an intelligent compatibility engine between users and jobs.


## Deliverables
- Skill matching
- Text similarity
- Match score
- Match explanation


## Tasks
- Create skill extractor
- Create skill normalization
- Create similarity engine
- Create weighted scoring
- Create explanation generator
- Create synonym mapping
- Create semantic matching MVP


## Acceptance Criteria
- Match score is consistent
- Match is explainable
- Similar skills are recognized
- Results are relevant
